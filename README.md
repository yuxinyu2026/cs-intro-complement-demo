## 一、项目简介

十进制加法人人会算，但计算机只有 0 和 1，还要处理负数。本程序把这件事拆成五个可观察的步骤：

1. 输入两个十进制整数，选择 8 位 / 16 位；
2. 自动转成补码，负数展示"写原码 → 数值位取反 → 末位加一"全过程；
3. 按位相加，逐位显示 本位和 与 向高位的进位（进位像多米诺一样传播）；
4. 用最高位进位与次高位进位的异或判定溢出（`C_out ⊕ C_n-1`）；
5. 把结果补码解释回有符号十进制，溢出时醒目提示"结果不可信"。

与"套壳计算器"的区别：**它演示的是过程，不是结果**。

## 四、主要功能

* **双位宽支持**：8 位（-128 ~ 127）与 16 位（-32768 ~ 32767），切换即时生效。
* **求补过程演示**：负数逐位展示 原码 → 反码 → 补码，最小负数（-128）单独提示"无原码表示"。
* **按位加法动画**：从最低位向最高位逐格高亮，同步显示本位和与进位。
* **溢出判定可视化**：双符号位异或结果直接显示，溢出时红色闪烁并给出原因。
* **单步 / 自动播放**：可暂停、可调速，便于课堂逐步讲解。
* **步骤日志**：右侧滚动输出每一步的中文说明，课后可对照复习。
