# images/ 目录说明

README 与设计文档里引用的图片都放在这里，**用相对路径**（如 `images/main_ui.png`），
不要用 `C:\...` 绝对路径，否则别人 clone 下来图片全是裂的。

## 需要补齐的文件（按优先级）

| 文件名 | 用在哪 | 要求 | 负责人 |
|---|---|---|---|
| `main_ui.png` | README 首屏 | 程序主界面截图，1250×760 原始尺寸，不要压缩到模糊 | 成员 B |
| `running_result.png` | README 功能演示 | 一次 `-5 + 3` 的完整结果（含步骤日志） | 成员 C |
| `overflow_demo.png` | README / PPT | `100 + 100` 溢出时红色提示的截图 | 成员 C |
| `ui_sketch.png` | 设计文档 4.4 | 手绘或 Figma 草图，证明"先设计后实现" | 成员 B |
| `conflict.png` | README 协作记录 | VS Code 里 `<<<<<<< HEAD` 冲突截图（Git 30% 分的证据） | 组长 |
| `git_graph.png` | README / PPT | 分支与合并的可视化（GitHub Network 或 `git log --graph`） | 组长 |

## 截图小技巧

- Windows 用 `Win + Shift + S` 截区域，保存 PNG；
- 截图前把窗口拉到 1250×760，避免出现桌面杂物；
- 不要用手机拍屏幕（有水波纹，评委会觉得不认真）。
